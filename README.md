# LaTales_runner 🐾

라테일 캐릭터가 내 데스크톱 위를 자유롭게 돌아다니는 데스크톱 펫 프로그램입니다.

화면 위를 걸어 다니다가 마우스로 잡아서 다른 창 위에 올려둘 수도 있고, 원하는 코디로 자유롭게 꾸밀 수 있어요.

## ✨ 주요 기능

- 🚶 **자율 이동**: 화면(멀티 모니터 지원) 위를 idle ↔ 걷기 상태로 자유롭게 돌아다녀요.
- 🖱️ **드래그 & 드롭**: 마우스로 들어올려서 다른 창(브라우저, 탐색기 등) 위에 올려둘 수 있어요. 놓으면 자연스럽게 낙하 애니메이션이 재생돼요.
- 👗 **코디 편집**: 헤어/피부/의상 등 원하는 조합으로 자유롭게 꾸밀 수 있고, 프리셋으로 저장/불러오기도 가능해요.
- 🙋 **이모티콘**: 게임 속 다양한 동작(이모티콘)을 즉시 재생하거나, 가만히 있을 때 자동으로 재생되도록 설정할 수 있어요.
- 👯 **여러 마리 키우기**: 캐릭터를 최대 5개까지 각자 다른 코디로 동시에 띄워둘 수 있어요.
- ⚙️ **세부 설정**: 캐릭터 크기/투명도 조절, 다른 창 위에 올라서기 켜기/끄기, 제자리에 서있기, Windows 시작 시 자동 실행 등을 지원해요.
- 🔄 **자동 업데이트**: 새 버전이 나오면 프로그램 안에서 바로 확인하고 업데이트할 수 있어요.

## 📥 다운로드 및 설치

[Releases](../../releases) 페이지에서 최신 버전을 받아주세요.

- **설치판**: `LaTales_runner-Setup-X.X.X.exe`를 실행하면 자동으로 설치됩니다.
- **압축판**: `LaTales_runner_vX.X.X.zip`을 원하는 폴더에 풀고 안에 있는 `Latales_runner.exe`를 실행하면 됩니다(내부의 `_internal` 폴더는 exe와 같은 위치에 있어야 해요).

별도의 라테일 클라이언트 설치 없이 바로 실행할 수 있습니다.

## 🖥️ 사용법

- **좌클릭 드래그**: 캐릭터를 들어서 원하는 위치나 다른 창 위에 올려두기
- **우클릭**: 코디 편집 / 이모티콘 / 캐릭터 관리 / 크기·투명도 / 기타 설정 메뉴 열기
